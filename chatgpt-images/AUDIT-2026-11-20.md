# Сверка официальной документации

Сверка: 20 ноября 2026. Выпуск 1.1.0. База: calculate main 7f190083a4bda9af124ed18764c5dbc91b3d5b13; сайт main 400e42d338349dd842c3340403ad5d2f13d87be7. Повторных PR по этому изменению до начала работы не найдено.

## Проверка выпуска

HTML собран `python manuscript/build.py`, PDF — `python manuscript/print.py` с Pandoc, ReportLab, lxml, DejaVu Sans и Inkscape, по README. Проверены локальные ссылки, уникальность якорей, соответствие оглавления главам и версии/даты во всех HTML. У PDF проверены открытие, текст всех страниц, закладки, внутренние переходы и растровые развороты всех страниц. Синтаксис встроенного JavaScript проверен Node.

Платные API-вызовы не выполнялись: совместимость примеров проверена по руководствам и справочнику эндпоинта. Доступность функций конкретного аккаунта не утверждается. Запуск Chromium в этой среде блокируется на создании Unix socket; проверка реального мобильного viewport и клика по кнопкам не выполнена. Адаптивные CSS и код кнопок не менялись.

Прямое HTTP-чтение Help Center возвращает 403; страницы и их содержание проверены через веб-поиск/открытие. Это ограничение метода, не доказательство неработающей ссылки. Markdown-путь changelog.md возвращает 404, обычная HTML-страница changelog открывается; ссылки рукописей на этот Markdown-путь не добавлялись.

Публикацию следует считать подтверждённой только после слияния обоих PR и совпадения SHA-256 всех 14 HTML/PDF с публичными URL. Штатный путь сайта: merge в main → серверный cron Namecheap → проверка HTTP и скачивания. Старый workflow Production deployment guard ничего не публикует; ручной обход не используется.

## Что изменено и почему

| Поверхность | Подтверждение | Решение |
|---|---|---|
| ChatGPT | [Английская справка](https://help.openai.com/en/articles/11084440-images-in-chatgpt): Images 2.6, Explore → Images, Save, GIF и именованные фотообразцы | Добавлены отдельные инструкции, условия развёртывания и ограничение правки загруженных GIF |
| Русский перевод | [Русская справка](https://help.openai.com/ru-ru/articles/11084440-images-in-chatgpt) ещё описывает 2.5 | Зафиксировано отставание перевода; прежний URL перенаправляется на канонический |
| API 2.6 | [Prompting](https://developers.openai.com/api/docs/guides/image-prompting), [generation](https://developers.openai.com/api/docs/guides/image-generation), [endpoint](https://developers.openai.com/api/reference/resources/images/methods/generate) | Пример PNG/medium/1536x1024 совместим; добавлены параметры, markup, SVG и GIF с ограничениями |
| Несогласованность справок | Вводный текст generation использует 2.5; раздел 2.6 и prompting описывают 2.6. Диапазон задержки GIF в гайде уже, чем в endpoint | Сохранён явно обозначенный диапазон гайда 20–2000 мс, не заявлен как универсальный предел сервера |
| Codex | [Image generation](https://learn.chatgpt.com/docs/image-generation) отдельно описывает встроенный инструмент | API model не переносится в кнопки и настройки ChatGPT/Codex |

Эти возможности частично появились до 6 ноября; выпуск исправляет и неполноту первой редакции, а не объявляет всё новым с даты предыдущей сверки.
