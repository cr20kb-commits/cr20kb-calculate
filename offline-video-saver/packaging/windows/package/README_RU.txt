CR20KB OFFLINE VIDEO SAVER — WINDOWS PORTABLE PREVIEW
=====================================================

Поддержка: Windows 10 22H2 / Windows 11, x64.
Docker, права администратора и установка Python не нужны.

БЫСТРЫЙ СТАРТ
-------------
1. Полностью распакуйте ZIP в обычную папку, например:
   D:\CR20KB-VideoSaver
   Не запускайте файлы прямо из окна ZIP.

2. Дважды щёлкните START_LOCAL.cmd.

3. При первом запуске программа скачает официальные версии yt-dlp,
   HandBrakeCLI, FFmpeg и Deno, проверит SHA-256 и сохранит их в папке tools.
   Обычно это 150–220 МБ загрузки и несколько минут ожидания.

4. Браузер откроется автоматически. Вставьте ссылку на плейлист, выберите
   профиль и запустите обработку.

5. Чёрное окно должно оставаться открытым. Ctrl+C в нём останавливает сервис.

С ТЕЛЕФОНА ИЛИ ПЛАНШЕТА
-----------------------
1. Компьютер и устройство должны быть в одной частной Wi-Fi/LAN сети.
2. Запустите START_FOR_PHONE.cmd.
3. Если Windows Firewall спросит разрешение, разрешите доступ только для
   частных сетей.
4. Адрес и ключ будут показаны в окне и записаны в PHONE_ACCESS.txt.
5. Не открывайте порт 8787 на роутере и не используйте этот режим в публичной
   сети.

ОБНОВЛЕНИЕ И РАСПОЛОЖЕНИЕ ФАЙЛОВ
--------------------------------
- UPDATE_TOOLS.cmd — обновить медиакомпоненты до текущих официальных релизов.
- data\ — временные задания и готовые файлы до автоматической очистки.
- tools\ — скачанные инструменты.
- config\ — локальный ключ и служебное состояние.
- logs\ — диагностические журналы при ошибке запуска.

ВАЖНО
-----
- Используйте только материалы, которые вы вправе скачивать.
- Программа не поддерживает DRM, cookies браузера и приватные аккаунты.
- YouTube может менять технические требования. При сбое сначала остановите
  сервис и запустите UPDATE_TOOLS.cmd.
- Portable preview пока не подписан цифровой подписью. Windows SmartScreen
  может показать предупреждение для CMD/Python из скачанного архива.
